## Команды на каждый день

```bash
node bench/swe/run-swe.mjs --agents builtin --instances <список> --concurrency 3   # Verified, перегон
node bench/run.mjs --agents builtin                                                # синтетика (69)
node bench/swe/corpus-summary.mjs                                                  # standings
node bench/swe/prepare-agent-bundle.mjs                                            # пересборка бандла (обязательно после правки агента!)
node bench/swe/prime-image-cache.mjs                                               # догреть кеш образов
```

После правки агента: пересобрать бандл, иначе бенчмарк гоняет прошлую сборку.
После правок — запись в `bench/swe/README.md` (Iteration log) и/или
`bench/ITERATIONS.md`, коммит в стиле истории (английский, повелительное
наклонение, суть и зачем).
