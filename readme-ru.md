# Acpio

Самостоятельно размещаемый веб-харнесс для агентов по [ACP](https://agentclientprotocol.com/):
**Cursor CLI**, **OMP**, **OpenCode** — или **встроенный агент**, который работает прямо в
сервере, так что чат запускается вообще без установки CLI. Канбан-**доски** ведут задачи по
нескольким проектам сразу, и каждая задача — это отдельный чат.
Чат со стримом рассуждений, tool calls и субагентов, настройки, светлая/тёмная тема в стиле META.

**Актуальная версия:** 0.1.43

> **Disclaimer (AI):** This project was developed in substantial part with the help of AI coding assistants. Review, test, and verify changes before relying on it in production.

## Установка из npm

Самый короткий путь — без сборки, на любой ОС:

```bash
npx acpio          # запустить без установки
npm i -g acpio     # глобально → `acpio`
```

Открывает http://localhost:18741; `acpio --help` и `acpio --version` отвечают,
ничего не запуская.

> **npm 11.17+** не запускает install-скрипты пакета, пока его не разрешат, а
> именно они собирают нативные модули — добавьте к командам выше
> `--allow-scripts=acpio,better-sqlite3,node-pty`.

### Другие способы установки

**Установка в один клик (Windows)** — нужен Node 20+ (ставится автоматически
при первом запуске):

```powershell
irm https://raw.githubusercontent.com/Alek7eeey/acpio/dev/scripts/setup.ps1 | iex
```

**Из npm через PowerShell (Windows)** — тот же бутстрап Node 20+, затем глобальный
`npm i -g acpio@latest` с разрешёнными install-скриптами: нативные модули собираются
сразу, а команда `acpio` запускает приложение потом:

```powershell
irm https://raw.githubusercontent.com/Alek7eeey/acpio/dev/scripts/install.ps1 | iex
```

Сохраните скрипт в файл, чтобы передать `-Version 0.1.42` (закрепить релиз) или
`-NoLaunch` (только установить):

```powershell
irm https://raw.githubusercontent.com/Alek7eeey/acpio/dev/scripts/install.ps1 -OutFile install.ps1
powershell -ExecutionPolicy Bypass -File install.ps1 -NoLaunch
```

**Из исходников (прод, один порт):**

```bash
npm install
npm run build
npm run start     # → http://localhost:18741 (UI + API + WebSocket)
```

**Разработка (hot reload):**

```bash
npm install
npm run dev       # UI http://localhost:18751, API http://localhost:18741
```

**Портативный дистрибутив (Windows):** `npm run dist` → `dist-app/acpio-win-x64.zip`,
распакуйте куда угодно и запустите `start.cmd`. В zip зашит нативный better-sqlite3,
поэтому собирайте его на той ОС/архитектуре, под которую распространяете (сейчас Windows x64).

Заметки:

- Прод: [http://localhost:18741](http://localhost:18741) — UI + API + WebSocket;
  dev: UI [http://localhost:18751](http://localhost:18751), API
  [http://localhost:18741](http://localhost:18741).
- Схема БД создаётся при старте сервера (идемпотентный `ensureSchema`); `.env`
  опционален — у всех настроек есть рабочие значения по умолчанию.
- Файл БД: `data/acpio.db` (переопределяется `DATABASE_PATH`); npm-версия держит его в
  пользовательском каталоге (`%LOCALAPPDATA%\acpio\data`,
  `$XDG_DATA_HOME`/`~/.local/share/acpio/data`,
  `~/Library/Application Support/acpio/data`), поэтому обновление не трогает ваши чаты.
- После `git pull` сделайте **hard refresh** в браузере (`Ctrl+Shift+R`) — кеш старых
  CSS/JS модулей скрывает новые правки.

## Харнессы

| Харнесс | Команда | Аргументы | Что нужно |
|---|---|---|---|
| Cursor CLI | `agent` | `acp` | — |
| OMP | `omp` | `acp` | — |
| OpenCode | `opencode` | `acp` | — |
| Встроенный агент | — | — | один OpenAI-совместимый endpoint (URL + ключ) |
| Свой агент | любой ACP-CLI | — | **Настройки → Агенты → Подключение → Свои агенты** |

1. В **Настройки → Агенты → Подключение** нажмите **Проверить** — сервер запустит
   ACP-процесс и покажет его модели.
2. Command, args и API key переопределяются в **Настройки → Агенты → Дополнительно →
   «CLI и права»**; permission policy для локальной работы: `Всегда разрешать`.
3. Нажмите **Подключить**, затем создайте чат.

Ненужный харнесс отключается тумблером в **Настройки → Агенты → Подключение**: он больше
не проверяется и исчезает из выбора агента, настроек моделей и полей CLI. Если чат «завис» —
нажмите **Стоп** и отправьте снова.

- **Встроенный агент** — агент внутри сервера: ничего не нужно ставить через `npm i -g`,
  отдельного логина тоже нет. В **Настройки → Встроенный агент** живут один или
  несколько OpenAI-совместимых endpoint'ов и отмеченные для агента модели; **Пресеты
  агента** режут того же агента на собственные профили (быстрый, с местом на размышление),
  и они попадают в выбор агента как обычный харнесс. Инструменты: `read`, `glob`, `grep`,
  `write`, `edit`, `bash`, `ask`, `plan` и MCP-серверы из **Настройки → MCP**.
- **Свои ACP-агенты** — **Настройки → Агенты → Подключение → Свои агенты**: укажите
  исполняемый файл и аргументы, и агент ведёт себя как встроенный харнесс.

Документация: [docs/usage-ru.md](docs/usage-ru.md) — харнессы, доски и плагины ·
[docs/adapters-ru.md](docs/adapters-ru.md) — как написать плагин харнесса.
Ядро харнесс-агностично: харнесс — это плагин `packages/adapter-*`, зарегистрированный в
`apps/server/src/adapters/registry.ts`, а интерфейс строит список провайдеров, поля CLI и
модели из `GET /api/adapters`.

## Доски

Доска создаётся вкладкой **Доска** в окне нового чата или кнопкой **Новая доска** в дереве
чатов; переименовать её можно в пилюле над колонками, а проекты добавить через **Папки
доски**. **+** у группы запускает задачу в этой папке — агент и тумблер **Стартовать сразу**
в форме решают, кто её выполнит и когда, а к первой отправке можно приложить файлы. Колонка
карточки следует за сессией: не запущенная задача стоит в **Todo**, живой ход — в **In
Progress**, а завершённый ход, ждущий вас вопрос или ошибка — в **Wait**, откуда **Готово** и
**Переоткрыть** двигают её руками. Задачи доски не показываются в дереве чатов, а удаление
доски удаляет и их. Подробности: [docs/usage-ru.md](docs/usage-ru.md#канбан-доски).

## Телефон и VPN

Сервер слушает все интерфейсы (`0.0.0.0`), поэтому UI открывается с телефона в том же
VPN/LAN: запустите acpio, откройте на телефоне `http://IP_ПК:18741` (dev: `:18751`) и при
необходимости разрешите входящий TCP **18741** (и **18751**) в файрволе.
**Настройки → Телефон и VPN** показывают шпаргалку с копированием адреса; кнопка
**Установить** в тулбаре добавляет сайт на домашний экран. `http://0.0.0.0:18741` — это адрес
прослушивания, а не адрес для браузера.

## Архитектура

Браузер ↔ REST/WS сервер ↔ запуск CLI харнесса через реестр адаптеров (`agent acp` /
`omp acp` / `opencode acp`, JSON-RPC NDJSON) или встроенный агент в процессе сервера ↔ SQLite.

События `session/update`, permissions, вопросы, планы и карточки субагентов отображаются в
ленте чата через нормализованные события адаптеров.

## Версионирование

Релиз выпускается по мере накопления изменений. Каждый релиз — это git-тег
`v<major>.<minor>.<patch>`, и тот же номер публикуется в npm. Список релизов — в `VERSIONS.md`,
новые сверху.

### `ACPIO_TAKEOVER=1` — принудительный захват занятой базы (только для человека)

Один acpio на один файл базы: старт на занятой базе отказывает и называет pid владельца.
С `ACPIO_TAKEOVER=1` отказ заменяется на «убить и захватить» — проверить, что владелец
действительно acpio, убить **всё дерево** его процессов и забрать лок.

**Этой возможностью может пользоваться только человек.** Агентам и CI использовать её
нельзя: она силой убивает того, кто держит лок, а два живых сервера на одной базе — ровно та
порча данных, от которой лок и существует. Без переменной поведение прежнее: отказ.
